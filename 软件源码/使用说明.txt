勋的软件

第一次换机
把整个 ZIP 解压到自己主力电脑的内置磁盘。打开解压后的「勋的软件」。
Windows 11 双击「Windows-打开词库.cmd」。Mac 双击「Mac-打开词库.command」。
首次启动会检查磁盘空间，显示资料恢复和校验进度。看到「资料恢复完成」后，程序会在默认浏览器打开。若提示空间不足，把解压后的整个文件夹移到空间足够的磁盘，再打开启动文件。
关键词、同行、原表及后续改动保存在同一文件夹的「我的资料」中。日常使用同一个入口。保留运行窗口，关闭后可按原方法重开。

在原电脑升级程序
在「备份与换机」选择「下载程序升级包」，把 ZIP 解压到新文件夹。退出旧版，打开新版对应系统的启动文件，再选择旧版的「我的资料」文件夹。新版会记住这个位置，接着使用原资料。原资料夹请保留在能访问的位置。
Mac 原生桌面版的资料通常在「~/Library/Application Support/ZhijianKeywordLibrary」。在选择文件夹的窗口中按 Shift+Command+G 可输入这个路径。

打开系统后先到「系统首页」。首页预设「行业关键词库」「软件与建站资料」「价值投资资料」「B2C 建站资料」四个一级类目。首页可添加一级类目；进入资料类目后可新增二级类目，保存资料时可选择归属或按识别词自动分类。进入关键词区可切换行业、跨行业查词，进入建站区可查看下列功能；「建站流程」会展开当前步骤。写一句进展点「保存记录」，做完点「完成此步」，也可点步骤名回看。每个项目的「Skill 管理」可以保存技能名称、用途和使用方法；「官网一级栏目规划」可添加、编辑页面名称、路径、关键词、用途与导航顺序。「建站资料库」支持单独存资料、跨行业搜索和自定义类型，可附文档、图片或代码。项目步骤里的记录会自动出现在资料库里。资料、附件随换机包一并迁移。

日常用法
打开系统首页，输入关键词或中文翻译可以跨行业查词。点「批量导入」，先看「导入到哪个行业」，再一次选好文件。导完点「查看这批词」或「查看这批同行」就能核对本批结果。
在关键词列表勾选目标词，翻页或调整筛选后仍可继续勾选。点「给 AI 建站用」，选产品分类页、产品详情页或行业文章，然后点「复制给 AI」。粘贴到使用的 AI 工具即可。需要读取实时词库时，使用「AI 取词」连接。
从首页的建站项目点「打开建站工作台」。访问过项目后，首页会记住该项目，并显示当前待做步骤。

建站项目自动记录
在「软件与建站资料」点项目名称切换网站，先看当前阶段和下一件事。点「让 Codex 接着做」继续，展开「完成标准与步骤操作」验收，进入「问题与解决办法」查待办。点「关联 Codex 对话」选一次，软件每 30 秒补存已关联对话的提问和回复文字，退出后下次打开补齐。点「以后新开的建站对话也自动收录」可在该网站工作文件夹添加项目说明。此后同一文件夹新开的对话，在 Codex 首次回报这个网站的进度后自动归档。Codex 回报的步骤、下一件事及明确记录的问题会出现在工作台。点「本步提示词」能复制自己的原话。「复用流程到新网站」可选新行业并沿用流程与原话，新项目从第一步开始。已连接本机资料库的 Codex 可读取已启用项目文件夹的站点进度和提示词。换到新电脑后，已归档的原文可以直接查找；通过新主机上的 Codex 对话启用新工作文件夹。

Skills 技能包与项目续做
打开「软件与建站资料 → Skills 技能包」收藏网址，或批量选择包含 SKILL.md 的 ZIP；技能卡上可编辑用途和用法，查看实际使用记录或下载原包。「连接 Codex」可在新电脑登记本机资料库。DEWEWE 项目内点「让 Codex 接着做 → 准备或查看源码文件夹」，把显示的文件夹作为 Codex 工作目录，即可从快照继续编辑。同一工作目录再次打开会保留编辑。源码改动保存在该工作目录；请将后续代码改动随代码仓库备份。项目进度、已关联对话和实际使用的技能随资料库保存。
从「行业关键词库 → 产品图库」查看全库和本行业图片数量。点分类查看下属图片，用「批量上传」指定整批图片的分类和来源，用「批量下载」保存当前筛选的原图，也可跨页勾选后下载。同行图在来源筛选中单列。原件、缩略图和 SSD 来源路径随换机包迁移。点图片可看来源、下载原件和调整分类。

使用建站案例
在「软件与建站资料」选择 DEWEWE PACK 包装官网（dwewe.com），点「这个项目怎么用」。可按时间查看原有对话，按步骤查找历史提问，并从原话点开当时的回复。资料记录里的附件可直接下载。点「复用流程到新网站」可只采用各步骤的通用模板，也可带上全部提示词。

添加资料
左侧「当前行业」可在包装袋、电池等行业间切换；点旁边的＋可以建立新行业。
「关键词库」可加词、导入自己的 Excel / CSV 或导出当前筛选的词与来源。每个行业按完整原文查重。拼写、词序、大小写或空格不同均分别保留。同一关键词来自多个网站时，各网站的来源明细都保留。
在「行业关键词库」点「批量导入」可以一次选多份 Excel、CSV 或 TSV。每张工作表单独识别，关键词和同行可混选。不能识别的工作表在结果中注明。点「批量导出」可勾选多个行业，打包下载关键词、来源、同行以及 AI 用的 JSONL。点「AI 取词」可复制本机 MCP 连接配置，供支持 MCP 的建站工具读取实时词库。换到新电脑后使用新主机提供的配置。
「同行网站」可添加或批量导入网址，也能下载网站清单。类型可选 B2B、B2C、两者兼有及未标注。
关键词的流量、DR、排名网址保留在来源明细里。同一词可在不同同行和市场有不同数据，最近的非空值用于当前展示。
「产品分类」可以查看袋类、盒类等词数和识别词。新增类型后会整理本行业已有词，以后导入也会自动归类。多个类型同时命中时在「待确认」里，手动修改的结果会保留。
「产品图库」可批量上传 JPG、PNG 和 WebP，在图片上添加完整关键词，或在词条里选图、设置首图。文件名去掉扩展名与在库词完全相同时自动配图。建站时点击「建站配图」下载原图、配图清单 CSV 和 image-map.json。图片也会随整库备份和换机包一起保存。
「导入记录」能找回某次上传的原表。手动修改类型可以纠正此前的归类。

在新电脑让 AI 帮忙建站
在主机先打开一次词库。进入「行业关键词库 → AI 取词」复制这台电脑的连接配置，再添加到支持 MCP 的 AI 工具。平时可以直接说“请从包装袋行业找邮寄袋相关词，写一个分类页草稿”。原始指标和来源可以让 AI 一起列出来核对。
「软件与建站资料 → 建站流程 → Skill 管理」记录每种技能的名称、用途和使用方法。在新电脑的 Codex 里说“请从 vercel-labs/skills 安装 find-skills，用它帮我找适合开发这个软件的技能”即可。若电脑已有 Node.js 和 npx，也可在终端运行：
npx skills add https://github.com/vercel-labs/skills --skill find-skills --agent codex --global --yes

同时用 Windows 与 Mac
选一台作主机。想从另一台读写同一份资料，请用主机上开启的外地网址。两台各自解压的词库将各自保存；需要更换主机时，在当前使用的词库点「导出 → 下载换机包」，再解压到新电脑的一个新文件夹。
还机前如果又加了资料，也请重新下载最新换机包。

偶尔从外地访问
在主机上另开同系统的「临时外地访问」并填写自己收验证码的邮箱。首次开启需要联网下载经校验的 Cloudflare 官方连接程序。窗口显示临时网址后，从另一台电脑在浏览器打开，按邮箱验证码提示登录。第一次再按词库登录页提示，用「我的资料/首次启用码.txt」设置私人密码。
保持主机开机、联网和登录；Mac 接电、开盖。每次最长 72 小时，关掉临时访问窗口会提前结束。再次开启时会生成新网址。词库密码仅保存在这台主机；换主机后按提示重新设置。
