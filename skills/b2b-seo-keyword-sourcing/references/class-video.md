# 课堂笔记与建站示例

依据用户提供的课堂实操短视频，时长 1 分 58.8 秒。视频中先总结白板上的找词流程，再解释如何从扩展词里反查同行。下列时间段来自本地语音转写并对照白板核查。

| 时间 | 老师讲的操作 | 阶段交付 |
| --- | --- | --- |
| 00:00–00:22 | 先让 ChatGPT 补一批中心词，再在 Semrush 扩展，按明确条件筛选和排除。 | 一份种子扩展导出。 |
| 00:22–01:09 | 让 ChatGPT 建候选同行名单。把候选站放到 Ahrefs Batch Analysis，按自然流量排序。先取前三个相关站，用 Semrush 看每个站的排名关键词。 | 候选域名表、流量判断、各站排名词及对应页面。 |
| 01:09–01:55 | 把中心词再扩成一个词组，用 Ahrefs Keywords Explorer 看哪些站分得这批词的流量。 | 按词组发现的新搜索同行，可补站点名单。 |

课堂提到的 20 和前 3 是示范取样。扩词数量在口述里有不同例子，实际取数按产品覆盖、市场、账号能力和现有数据决定。

## 对照当前工具报告

- 用 Keyword Magic Tool 的包含、排除条件检查种子扩展，按目标国家保存查询与导出。 [Semrush Keyword Magic Tool](https://www.semrush.com/kb/617-keyword-magic-tool-manual)
- 在 Batch Analysis 比较同国家下的预计自然流量，保留具体范围和数据日期。 [Ahrefs Batch Analysis](https://help.ahrefs.com/en/articles/79496-how-to-use-batch-analysis-to-analyze-many-urls-domains-at-once)
- 使用 Traffic Share by Domains 检查目标词组的搜索流量分布。 [Ahrefs Traffic Share](https://help.ahrefs.com/en/articles/2073915-how-can-i-find-new-competitor-websites-using-the-traffic-share-reports)
- 用 Organic Rankings 的 Positions 导出每条词的排名页、位置、搜索量与可得流量。 [Semrush Organic Positions](https://www.semrush.com/kb/494-organic-rankings-positions-report)

## 包装袋站示例

用行业库已有的 `poly mailers` 作种子。按实际产品核对定制印刷、尺寸、材质和批量采购等需求。从可读的美国市场排名数据识别对手与排名页，保留原网址和来源。之后可以把通用选型留给快递袋类目页，把一个确有规格、产品图和供货依据的型号留给详情页。是否需要新增页面，交给网站架构和已有页面核对来决定。

给 Codex 的示例请求。用我的包装袋行业词库和我已有的导出，按这个 Skill 检查美国市场的 poly mailers。请列出由中心词扩展的候选、已有数据能支持的搜索同行，以及每个重点词的排名页与来源。先交候选词和证据，页面改动留到我确认。
